# 🔍 GitHub Profile Finder

A modern and responsive GitHub Profile Finder built using HTML, CSS, and JavaScript.

This application allows users to search for any GitHub profile and view important information such as repositories, followers, following count, bio, location, join date, and more using the GitHub API.

---

## ✨ Features

- Search any GitHub user
- Real-time data using GitHub API
- Profile picture and bio
- Public repositories count
- Followers and following count
- Account active days calculation
- Location and company details
- Blog/website link support
- Join date information
- Skeleton loading animation
- Error handling for invalid usernames
- Responsive design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- GitHub REST API

## 🚀 How It Works

1. Enter a GitHub username.
2. Click the search button or press Enter.
3. The application fetches data from GitHub API.
4. A loading skeleton is shown while data is loading.
5. User information is displayed dynamically.
6. Error messages are shown for invalid usernames.
